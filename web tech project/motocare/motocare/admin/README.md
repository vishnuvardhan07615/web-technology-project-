# Admin Module (Stage 2 Placeholder)

## Overview
The `admin/` directory will contain the administrative control center for the **MotoCare** workshop manager and store owner.

## Planned Stage 2 Files
- `login.php` - Secure admin authentication and role verification.
- `dashboard.php` - Overview dashboard showing key metrics (daily bookings, revenue, vehicle flow, mechanics on duty).
- `customers.php` - Customer relationship management (view, search, and manage registered bike owners).
- `bookings.php` - Slot scheduling, service requests approval, and mechanic task allocation.
- `mechanics.php` - Mechanic staff roster, workload allocation, performance tracking, and attendance.
- `services.php` - Catalog management of service packages, pricing, labor charges, and categories.
- `spare-parts.php` - Spare parts inventory control, minimum stock alerts, suppliers, and part billing.
- `reports.php` - Revenue analytics, monthly servicing volume, customer retention, and downloadable PDF reports.

## Database Integration
This module manages administrative records across:
- `admin_users`
- `customers`
- `vehicles`
- `bookings`
- `mechanics`
- `services`
- `spare_parts`
- `bills`
